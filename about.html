About Our Project

AI Campus Placement Predictor & Interview Assistant is an intelligent web application designed to help students evaluate their placement readiness using Machine Learning and Artificial Intelligence. The system predicts whether a student is likely to be placed based on academic performance, internships, projects, aptitude, communication skills, and training. It also provides an AI-powered interview assistant that analyzes interview responses and offers personalized feedback to improve confidence and employability. Our goal is to help students identify their strengths, improve weak areas, and prepare more effectively for campus recruitment.

🎯 Project Objectives

  • ✔ Predict placement chances using Machine Learning.
  • ✔ Help students identify areas for improvement.
  • ✔ Provide AI-generated interview feedback.
  • ✔ Improve technical and communication skills.
  • ✔ Generate a professional placement report.

🛠 Technologies Used

🐍 Python

Core programming language used for developing the application.

🌐 Flask

Backend framework used to build the web application.

🤖 Machine Learning

Random Forest, Decision Tree and Logistic Regression models for prediction.

📊 Data Science

Pandas, NumPy, Matplotlib and Seaborn for data analysis and visualization.

🧠 AI & NLP

Natural Language Processing for evaluating interview responses.

💻 VS Code & Jupyter

Development environment for coding, training and testing the project.

📊 Dataset Information

This project is trained using the Campus Placement Dataset (Kaggle). The dataset contains important attributes such as CGPA, Internships, Projects, Workshops, Aptitude Test Score, Soft Skills Rating, Placement Training, SSC Marks, HSC Marks and Placement Status. These features enable the Machine Learning model to make placement predictions and generate personalized recommendations.
